Number tracker

Tap a number once to cross it out, twice to circle it as in the code.

How to play
  • Each clue is a guess someone already tried, with what was right about it.
  • Well placed means the right number in the right box. Wrongly placed means the number is in the code, but in a different box.
  • No number is used twice in a code.
  • Test my guess shows ✓ for each clue your guess agrees with, ✗ for each one it breaks. It doesn't use up a try.
  • Inside every safe are the Crown Jewels. Crack it in 3 tries or fewer with no help for ★★★.
  • Stuck? New clue adds another guess to study (up to 3). Reveal a number puts one correct number in its box. Each one costs a star.

The same set number and level always make the same puzzles, so the whole class can work on one set. Use your browser's Print to print a set. The answer key prints on its own page only when it has been unlocked with the teacher code.
