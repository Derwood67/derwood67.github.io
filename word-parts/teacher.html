The students below are made up so you can see how the dashboard works. To collect real work, connect a Google Sheet once:

  1. Make a new Google Sheet. Open Extensions, then Apps Script.
  2. Paste in the code from word-parts/Code.gs. Change TEACHER_CODE to a code only you know. Save, then run setup once.
  3. Choose Deploy, then New deployment, then Web app. Set "Execute as" to Me and "Who has access" to Anyone.
  4. Copy the web app URL into word-parts/config.js on GitHub.
